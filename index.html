Detection Algorithm — 8 Layers

Layer 1–4: Time & Motion

⏱️ Clock vs Engine time gap > threshold+35
🚀 Velocity too low between stops (dawdling)+25
📐 Miles driven vs clocked hours mismatch+30
🌅 Late first GPS movement after clock-in+20
🏁 Truck stopped moving before clock-out+20
🚨 GPS movement detected after clock-out+45

Layer 5–6: Stop Pattern Analysis

🅿️ Unexplained stop at unknown location+25
🔁 Micro-stop cluster (many short stops)+20
🗺️ Repeated same non-delivery location+15
🔴 Warehouse geofence — clocked not moving+25
📍 Route deviation >2mi from expected path+10
⏳ Excessive dwell vs stop type baseline+20

Layer 7: Personal Baseline Deviation

📈 Today's pace vs driver's own 30-day avg+0–30
Stop count below personal baseline+15
Avg stop duration above personal baseline+20
Completion time vs personal avg for route+25
Baseline uses simulated 30-day history. Wire to Motive historical API for real baseline computation. Higher weight given to established drivers (60+ day history).

Layer 8: Peer Benchmarking

Driver efficiency vs route peer group avg+0–25
Miles/hr below peer group floor+20
Stop rate below peer group floor+15
Compares each driver against all drivers running similar routes (same day, same region). A 25%+ deviation from peer median triggers flags. Accounts for traffic — all peers on same day experience same conditions.
